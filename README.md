# CodeForces Practice Log

My competitive programming solutions — mostly Codeforces problems written in C++ and C#. This is a working practice archive, not a library: filenames follow the problem they solve (e.g. `cpp/problem_e.cpp`), and later-numbered files are retries or alternate approaches to the same problem.

## Layout

```
cpp/       C++ solutions (primary language)
csharp/    C# solutions
```

## Status

Active practice log — updated as I solve problems. Solutions are kept as-written for each attempt rather than polished, so the history of my approach is visible.
